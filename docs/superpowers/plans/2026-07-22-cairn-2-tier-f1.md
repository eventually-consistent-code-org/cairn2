### Task 1: Workspace context — discovery, focus, resolution

**Files:**
- Create: `server/src/workspace/context.ts`
- Test: `server/test/workspace-context.test.ts`

**Interfaces (produces):**
```ts
export interface WorkspaceMember { name: string; path: string; configured: boolean; absPath: string; }
export interface WorkspaceInfo { workspace: string; root: string; members: WorkspaceMember[]; focus: string | null; }
export function findWorkspace(launchDir: string): WorkspaceInfo | null;   // walk up for cairn-workspace.json
export function setFocus(launchDir: string, project: string | null): { focus: string | null; projectDir: string };
export function resolveProjectDir(launchDir: string): string;
```
Semantics per spec §2: discovery walks parents to filesystem root; member `configured` = `<absPath>/cairn.json` exists; `setFocus` validates member exists AND configured (`CairnError("CONFIG_INVALID", …)` naming the member and the fix — "add a cairn.json to <path>" / "not a member of <workspace>"), `null` clears; focus file `.cairn/basecamp/focus.json` under the workspace ROOT, atomic write; `resolveProjectDir`: no workspace OR no focus → `launchDir`; focus → member absPath; focus names a now-invalid member → CONFIG_INVALID (never silent fallback). Malformed `cairn-workspace.json` → CONFIG_INVALID naming the file (never treated as no-workspace — silent single-project fallback on a typo'd workspace file is the trap).

### Task 3: Resolver transform + five tools + stage-end dist

**Files:**
- Modify: `server/src/index.ts`
- Test: `server/test/mcp.test.ts` (60 pin + new cases)

**The transform (mechanical, but THE risk item — do it exactly):**
1. `buildServer(deps: { projectDir: string; tracker?: Tracker })` keeps its signature. Treat `deps.projectDir` as the LAUNCH dir. Add at the top of `buildServer`:
   ```ts

   const dir = (): string => resolveProjectDir(launchDir);
   ```
2. Replace EVERY OTHER `deps.projectDir` use in the function body with `dir()` (the launchDir const above is the only survivor). ~60 sites; `grep -n "deps.projectDir"` after — exactly one hit.
3. Per-dir memos:
   ```ts

   if (deps.tracker) trackers.set(launchDir, deps.tracker);       // test injection preserved
   const getTracker = async (): Promise<Tracker> => {
     const d = dir();
     let t = trackers.get(d);
     if (!t) { t = new CachedTracker(await makeTracker(loadConfig(d))); trackers.set(d, t); }
     return t;
   };
   const memIndexes = new Map<string, MemoryIndex>();
   const getMemIndex = (): MemoryIndex => { /* same map pattern on indexDbPath(dir()) */ };
   const getCtx = (): ActiveContext => new ActiveContext(dir());   // replaces the build-time ctx const
   ```
   Replace every `ctx.` use with `getCtx().`; delete the old `ctx`/`tracker`/`memIndex` singletons.
4. Register the five tools (after `audit_record`, before `map_set` or after — pick one, note it):

Read-only, never writes focus.
   - `board_get` / `board_update` per Task 2 signatures (`patch: z.record(z.union([WorkstreamPatchSchema, z.null()]))`).
