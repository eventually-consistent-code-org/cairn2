The observation buffer's error flag is dead. hooks/scripts/posttooluse-observe.mjs derives `error` from tool_response.is_error / success / exit_code, but a tool call that FAILS emits no PostToolUse event at all, so it never reaches the hook: a deliberate Bash `exit 3` on 2026-10-12 left no row, and 0 of 1341 rows across a thirteen-wave guard-hardening phase (879 Bash calls) carried error:true. Retro's error→retry churn analysis therefore always sees nothing; only the hotspot (edit/write count per file) signal is real. Capturing failures needs the PostToolUseFailure event wired beside PostToolUse in hooks/hooks.json.
