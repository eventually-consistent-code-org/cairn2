MCP input-schema (zod) refusals come back as the SDK's plain text ("Input validation error: …"), not cairn's JSON error envelope. The mcp.test `call` helper JSON.parses the first content block and throws SyntaxError on them, so a test asserting a schema-level refusal must go through `client.callTool` directly and match the text — cairn-level refusals (thrown inside the handler) still parse as `{code: …}`. Bit #194's first schema test.
